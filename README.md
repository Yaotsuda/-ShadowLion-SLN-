# ShadowLion (SLN) Token Overview

ShadowLion (SLN) is a fixed‑supply utility token deployed on the Polygon (PoS) blockchain.
The project focuses on predictable token behavior, transparent distribution, and simple
on‑chain utility suitable for staking mechanisms, decentralized tools, and future ecosystem
incentives.

## 2. Distribution Model

ShadowLion uses a fixed‑supply distribution model.  
All tokens were minted at the Token Generation Event (TGE), and no additional minting or
inflationary mechanisms exist. The supply is allocated as follows:

### Distribution Breakdown
- **Creator Allocation:** 100,000,000 SLN  
  Tokens retained by the project creator for operational needs, development, and long‑term support.

- **Staking & Rewards Pool:** 900,000,000 SLN  
  Tokens reserved for staking rewards, ecosystem incentives, community programs, and future
  reward mechanisms introduced as the project evolves.

### Vesting / Lockups
- No vesting schedules  
- No locked wallets  
- All tokens fully unlocked at TGE

### Emission
- No additional token emissions  
- All future rewards distributed strictly from the existing supply

## 4. Project History

ShadowLion originated as an experimental utility token designed to support transparent and
predictable on‑chain interactions. The project began with a focus on simplicity and reliability,
aiming to provide a stable asset for staking, testing decentralized tools, and powering small‑scale

Over time, ShadowLion evolved into a structured utility token with a fixed supply and a clear
distribution model, maintaining a minimalistic and transparent approach to token economics.
